# UptimeWatch

Сервис мониторинга доступности сайтов на .NET: фоновые HTTP-проверки, история и аптайм, инциденты, живой дашборд и алерты в Telegram.

> Статус: проект в стадии проектирования. Код пока не написан.

## Стек

ASP.NET Core (.NET 9), Blazor Server, SignalR, EF Core, PostgreSQL, ASP.NET Core Identity, xUnit, Testcontainers, Docker Compose, GitHub Actions.

## Возможности первой версии

- Мониторы: URL, интервал, ожидаемый код ответа.
- Фоновые проверки, история результатов, аптайм за 24 часа, 7 и 30 дней.
- Инциденты с длительностью простоя.
- Живой дашборд без перезагрузки страницы.
- Алерты в Telegram о падении и восстановлении.
- Регистрация и вход: у каждого пользователя свои мониторы.
